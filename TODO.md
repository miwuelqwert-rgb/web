# Resultados de ColectionsChile

- [ ] **Catálogo público y enlace compartible:** ColectionsChile debe funcionar como una página web compartible mediante un enlace personalizado con el mismo nombre, mostrar la identidad ColectionsChile, adaptarse a celulares y computadores y usar verde, blanco y negro.
- [ ] **Productos y disponibilidad:** El público debe poder ver artículos como Hot Wheels con fotos, descripción, cantidad disponible y un estado claramente visible que indique si están disponibles o agotados.
- [ ] **Comentarios por producto:** El público debe poder escribir comentarios o consultas sobre la disponibilidad de cada producto y ver los comentarios existentes.
- [ ] **Panel privado de administración:** El apartado de administración debe estar protegido y ser accesible solo para la persona dueña mediante autenticación real.
- [ ] **Gestión de inventario:** La persona dueña debe poder agregar y editar productos, reemplazar fotos, actualizar descripciones, cambiar cantidades y eliminar productos o comentarios desde el panel.
